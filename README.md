A repository for developing and maintaining custom claude skills:

**document-ticket**
Intended to be used when a (/)implement of a github ticket needs dedicated documentation. E.g., to explain an implemented algorithm or what the implemented changes deliver. Instead of a diary style explanation (first I did this, then this) it attempts to explain the logical phases, both in text, diagrams and concrete examples. It can also produce a code snippets appendix highlighting the key changes.
